# Sample output

Generated by `python src/analysis.py` on the **synthetic** file `data/sample_ad_events.csv` (random numbers, not real campaigns). It shows what the pipeline produces. Replace with output from a real public dataset before drawing conclusions.

| File | What it is |
|---|---|
| `campaign_kpis.csv` | CTR, CVR, CPC and ROI per campaign |
| `daily_impressions.csv` | Daily impressions and 7-day moving average |
| `forecast_next_30d.csv` | Flat 30-day impressions forecast |
| `run_log.txt` | Console output, including the 30-day backtest MAPE |
| `ctr_roi_by_campaign.png`, `impressions_forecast.png` | Charts |
